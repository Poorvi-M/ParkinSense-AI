# ParkinSense-AI

## Overview
ParkinSense-AI is an AI-powered web application designed to assist in the early detection of Parkinson's disease. It combines a machine learning model with a web-based interface, enabling users to interact with the system through an intuitive frontend while the backend processes requests and generates predictions.

## Project Structure

```
full-project/
├── frontend/      # HTML, CSS and JavaScript interface
├── backend/       # FastAPI backend and API routes
├── model/         # Machine learning model files
```

## Features

- Parkinson's disease prediction
- User authentication
- Patient dashboard
- Diagnosis interface
- Severity assessment
- Treatment recommendations
- Progress tracking
- Reports and history
